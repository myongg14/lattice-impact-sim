# 낙하 충격 시뮬레이터

고등학교 과학과제연구 발표용 웹 시뮬레이터입니다. PETG로 3D 프린팅한 6×6×6cm 시험편 세 종류(**Gyroid, Octet, Honeycomb**)의 상대밀도를 같게 맞추고, 충격체를 떨어뜨렸을 때 아래 로드셀에 전달되는 **최대 충격력**과 **충격 지속시간**을 비교합니다.

> 이 결과는 단순화된 모델로 계산한 값이라 실제 값과 다를 수 있습니다. 구조 사이의 **경향**을 보는 데 쓰고, 실험값으로 계수를 보정해 주세요.

## 실행 방법

1. 이 저장소를 내려받습니다(초록색 **Code** 버튼 → **Download ZIP** 후 압축 풀기).
2. `index.html`을 더블클릭해서 크롬, 엣지, 사파리 같은 브라우저로 엽니다. 설치할 것은 없습니다.
3. 그래프 라이브러리(Chart.js 4.4.1)와 3D 라이브러리(Three.js r128)를 인터넷(CDN)에서 받아 오기 때문에 **처음 열 때 인터넷 연결이 필요합니다**.

GitHub Pages가 켜져 있으면 `https://myongg14.github.io/lattice-impact-sim/`에서도 열 수 있습니다.

### 발표할 때

- 오른쪽 위 **전체화면**: 브라우저 전체화면으로 바꿉니다(Esc로 끝냄).
- **발표 모드**: 글씨와 그래프를 크게 키웁니다.
- **어두운 화면 / 밝은 화면**: 프로젝터 환경에 맞게 고릅니다.

## 모델 수식

### 1. 장치 모형 (1자유도 충돌 모델 + 로드셀 전달 단계)

```
충격체 m1 ─접촉 스프링 k_c─ 상판 m2 ─시험편(비선형)─ 하판 m3 ─로드셀 k_l─ 바닥
```

핵심은 충격체가 시험편이라는 비선형 스프링에 부딪히는 1자유도 충돌입니다. 여기에 실제 장치처럼 상판, 하판, 로드셀을 차례로 붙여서 **로드셀이 읽는 힘**을 출력합니다. 아래쪽 변위를 +로 하면

- 충돌 속도: `v0 = √(2gh)`, 충돌 에너지 `E0 = m1·g·h`
- 접촉력: `F_c = max(0, k_c·(x1−x2) + c_c·(v1−v2))` (떨어지면 0)
- 시험편 힘: `F_s = max(0, σ(ε)·A + c_s·(v2−v3))`, `ε = (x2−x3)/L`, `A = L²`
- 로드셀 힘: `F_l = k_l·x3 + c_l·v3 − (m2+m3)·g` (판 무게는 영점 조정)
- 운동방정식
  - `m1·a1 = m1·g − F_c`
  - `m2·a2 = m2·g + F_c − F_s`
  - `m3·a3 = m3·g + F_s − F_l − (m2+m3)·g`
- 감쇠계수는 감쇠비 ζ로 정합니다: `c = 2ζ·√(k·m)`
- 기본값: 나무 상판 60 g, 나무 하판 60 g(측정 전 추정값), 충격체-나무판 접촉 강성 3×10⁷ N/m, 로드셀 강성 1×10⁸ N/m(로드셀 사양 확인 전 대표값)

### 2. 수치적분과 샘플링

- 4차 룽게-쿠타(RK4), 기본 `dt = 2 μs` (설정에서 바꿔도 최대 10 μs)
- 로드셀 출력은 1차 저역통과 필터(기본 4 kHz)를 거친 뒤 **샘플링 속도(기본 10 kHz)** 간격으로 한 점씩 뽑습니다. 실제 측정처럼 짧은 펄스는 최대값을 놓칠 수 있고, 이때 화면에 경고가 뜹니다.
- 충격체가 위로 떨어져 나간 뒤 2 ms 더 계산하거나, 충격체가 멈추면 끝냅니다.

### 3. 구조별 물성 (Gibson–Ashby 스케일링)

상대밀도 ρ*, PETG 영률 `E_s = 2.0 GPa`, 항복강도 `σ_s = 50 MPa`, 밀도 1.27 g/cm³.

| 구조 | 탄성계수 E | 붕괴(피크) 응력 σ_pk | 고원 응력 σ_pl | 근거 |
| --- | --- | --- | --- | --- |
| Octet (신장 지배형) | `(1/9)·E_s·ρ*` | `0.3·σ_s·ρ*` | `0.8·σ_pk` (지주 좌굴로 약간 연화) | Deshpande·Fleck·Ashby(2001) |
| Gyroid (굽힘 지배형에 가까움) | `0.25·E_s·ρ*²` | `0.3·σ_s·ρ*^1.5` | `σ_pk` (거의 평평, 완만히 증가) | Gibson–Ashby 굽힘형 |
| Honeycomb (면외 압축) | `E_s·ρ*` | `2.0·σ_s·ρ*^(5/3)` | `0.5·σ_pk` (셀이 클수록 더 떨어짐) | 벽 소성 좌굴 |

- 붕괴 응력은 꽉 찬 재료가 눌리는 한계 `σ_s·ρ*`를 넘지 않게 제한합니다.
- 가장자리 셀 효과: E와 σ에 `(1 − α·셀크기/시편크기)`를 곱합니다(α = 0.5).
- Honeycomb 셀 크기 효과: 고원비 = `0.5 − 0.12·(셀크기−10mm)/10mm`. 접힘 반파장 `H = 0.821·(l²t)^(1/3)` (Wierzbicki)으로 고원 구간의 출렁임 주기를 정합니다. 여기서 `l = D/√3`(D: 셀 크기), `t = ρ*·D/2`(벽 두께).
- 계수는 모두 `js/config.js`의 `structures`에 있고, [모델 설정] 탭에서도 바꿀 수 있습니다.

### 4. 응력-변형률 곡선 (처음 누를 때)

1. **선형 탄성**: `σ = E·ε` (ε ≤ ε_Y = σ_pk/E)
2. **붕괴 고원**: 피크 σ_pk에서 dropStrain 동안 σ_pl로 부드럽게 내려간 뒤
   `σ = σ_pl·(1 + h·(ε − ε0))·(1 + w·sin(2π(ε − ε0)/λ))` (h: 고원 기울기, w: 출렁임, Honeycomb만 w > 0)
3. **치밀화**: `ε_D = 1 − 1.4·ρ*` 이후 `σ = σ_고원끝 + E_s·x³`, `x = (ε − ε_D)/(1 − ε_D)`

### 5. 하중 제거와 히스테리시스(에너지 흡수)

지금까지의 최대 변형률 ε_max를 기억합니다.

- 탄성 범위(ε_max ≤ ε_Y) 안이면 같은 직선으로 돌아옵니다.
- 그보다 많이 눌렸으면 기울기 `E_u = max(E, 3·σ_max/ε_max)`인 직선으로 내려와 잔류 변형률 `ε_res = ε_max − σ_max/E_u`에서 힘이 0이 됩니다. 치밀화 구간에서는 이 직선이 처음 누를 때의 곡선보다 위로 올라가지 않도록 기울기를 더 키웁니다(에너지가 생겨나지 않게).
- 다시 누르면 같은 직선을 따라 올라가다가 ε_max에서 원래 곡선으로 돌아갑니다.
- 재료 점성: 감쇠비 ζ = 0.05

**흡수 에너지**는 시험편이 받은 일 `W = ∫F_s dδ`입니다. 누를 때와 돌아올 때 곡선 사이의 넓이와 점성 손실을 합한 값입니다.

### 6. 결과 지표

- **최대 충격력**: 샘플링한 로드셀 힘의 최대값(표에는 샘플링 전 '연속' 최대값도 표시)
- **충격 지속시간**: 힘이 최대값의 10%를 처음 넘은 시점부터, 최대값 이후 다시 10% 아래로 떨어진 시점까지(샘플 사이는 직선 보간). 기준(%)은 [모델 설정]에서 바꿀 수 있습니다.
- **충격량**: `I = ∫F dt` (측정 신호 전체). 충격체 운동량 변화 `Δp = m1·(v충돌 + v반발)`와 비교합니다.
- **경고**: 바닥 닿음(완전 압축: ε_max > ε_D + 0.5·(1−ε_D) 또는 치밀화 뒤 응력 > 5·σ_pk), 치밀화 진입, 벽·지주가 노즐(0.4 mm)보다 얇음, 샘플링이 최대값을 5% 넘게 놓침, 충격 중 측정점이 6개 미만

### 7. 3D 형상

- **Gyroid**: `sin x cos y + sin y cos z + sin z cos x = t`. 시트형(`|f| ≤ t`)으로 보고, 부피 비율이 ρ*가 되는 t를 계산해서 그립니다(Surface Nets). 시험편 전체 보기에서는 가볍게 중간면(t = 0)만 그립니다. 벽 두께 ≈ `ρ*·a/3.09`.
- **Octet**: FCC 격자의 면 대각선과 면 중심을 잇는 지주. 지주 지름은 `ρ* ≈ 6√2·π·(r/l)²`, `l = a/√2`로 계산합니다.
- **Honeycomb**: 하중 방향(세로)으로 뻗은 정육각 벌집. 벽 두께 `t = ρ*·D/2`.

## 모델의 한계

- 시험편을 하나의 비선형 스프링으로 봅니다. 층별로 차례로 무너지는 국부 변형이나 파단, 층간 박리는 표현하지 않습니다.
- 변형률 속도에 따른 강도 증가, 온도, 출력 결함(빈틈·층 접착)은 넣지 않았습니다. 3D 프린팅 시편은 보통 문헌값보다 약하므로 실험값으로 C 계수를 보정하는 것이 좋습니다.
- 로드셀은 하나의 스프링-질량으로 단순화했습니다. 실제 로드셀과 증폭기의 주파수 특성은 다를 수 있습니다.
